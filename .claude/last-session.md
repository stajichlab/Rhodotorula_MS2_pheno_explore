## Concurrent session note (color-phenotype-metabolite power analysis)

A second Claude Code session (this one) was active in parallel building
`analysis/phenotype_metabolite_association/scripts/09_power_analysis.py` — added after
the copper-AUC ingestion note above; that ingestion work is untouched by this session.

**What was added:** a simulation-based power analysis for the Tier1 FDR detection
criterion (|ρ|>0.30 & q<0.05) used throughout scripts 02-08. For a grid of true ρ,
synthesizes a feature correlated with the real phenotype residual at that ρ and
re-runs the two-stage BH-FDR against the *real* background null p-values from the
7,341-feature scan, for both the pooled (n=550) and *R. mucilaginosa*-only (n=415)
designs.

**Result, and why it matters:** minimum detectable ρ at 80% power ≈0.34 for both
designs; power to detect ρ=0.20 (the largest ρ ever actually observed in the corrected
scan) is only 0-2%. This recalibrates every "negative result" claim from earlier in
this analysis: the five converging null checks (FDR, permutation, holdout×2,
multivariate×2) confidently rule out anything ≥ρ≈0.34 — which safely covers the
original ρ=0.7+ headline claims — but are **uninformative** about a true, modest
ρ≈0.15-0.30 effect. `docs/FEATURE_ANALYSIS.md`, `analysis/ANALYSIS_MANIFEST.md`, and
`analysis/phenotype_metabolite_association/PHENOTYPE_METABOLITE_ASSOCIATION.md` were
updated with this caveat; a findings entry was logged in
`.living/findings/color-phenotype-metabolomics.md` (F-005).

**Committed:** yes, but push has repeatedly failed in this shell — no SSH agent/key
