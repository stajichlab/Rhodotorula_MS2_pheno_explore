## pigment_pathway_targets

```yaml
name: pigment-pathway-targets
purpose: Candidate compound (formula, monoisotopic mass, adduct m/z) list for the Rhodotorula carotenoid pathway, DOPA-melanin precursors, and mycosporine-like amino acids, used for targeted m/z matching against the MS2 feature table
source: computed from molecular formulas (see build_target_list.py docstring for pathway/compound provenance and confidence tiers), not a validated standards library
date_added: 2026-08-11
format: CSV, generated by build_target_list.py
tags: [carotenoid, melanin, mycosporine, pigment, targeted-metabolomics, rhodotorula]
```

Compound list (17 compounds × 4 adducts = 68 target rows) used by
`analysis/pathway_targeted_association/` to find features that FDR/permutation testing
on the full untargeted feature set was underpowered to detect
(`analysis/phenotype_metabolite_association/` finding F-005). Regenerate with
`python3 build_target_list.py` in this directory; masses are computed at run time from
molecular formulas, not hardcoded, so re-running is deterministic and auditable.
